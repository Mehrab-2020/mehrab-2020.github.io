16x2 LCD with I2C

The 16x2 Character LCD Display Module with an integrated I2C interface allows you to display text and numbers using only two pins (SDA/SCL) on your Arduino or ESP32.

Key Features:

  • 16 characters x 2 lines display
  • Blue backlight with white characters
  • Integrated I2C module (PCF8574T)
  • Adjustable contrast via potentiometer
  • Operating Voltage: 5V
