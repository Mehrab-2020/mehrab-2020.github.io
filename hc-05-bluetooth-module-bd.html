The HC-05 is a widely popular, low-cost serial Bluetooth module. It can be set up as a Master or Slave device, making it incredibly versatile for creating point-to-point wireless connections between microcontrollers, PCs, and smartphones.

Key Features:

  • Bluetooth 2.0+EDR (Enhanced Data Rate)
  • Default Baud Rate: 9600 (Data Mode), 38400 (AT Mode)
  • Operating Voltage: 3.6V to 6V DC (5V recommended)
  • Range: Up to 10 meters
  • Configurable via AT commands (Name, Role, Baud Rate)
